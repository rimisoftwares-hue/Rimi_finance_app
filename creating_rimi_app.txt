

To open new laptop

# 1. Install Docker Desktop on the new laptop
#    → https://www.docker.com/products/docker-desktop

# 2. Navigate to project folder
cd Rimi_finance_app

# 3. Run — Docker builds everything automatically
docker compose up --build
